About DevOps Quiz

      
DevOps Quiz is a free, open-source practice site by Yousaf K Hamza (Yousaf Hamza), a Senior DevOps and Platform Engineer based in Dubai. It has 600+ questions at four severity levels, from quick concept checks to on-call incidents you work through in a simulated terminal: reading crash logs, rolling back deployments, fixing security groups, recovering Git branches and repairing Windows services.

      
Topics: Kubernetes, AWS, Terraform, Docker, Linux, Bash scripting, PowerShell, Python, Ansible, Git, CI/CD with GitHub Actions, GitOps with Argo CD, networking, observability with Prometheus and OpenTelemetry, DevSecOps, and AI/MLOps. Use it to prepare for DevOps interviews and certifications such as CKA, AWS Solutions Architect and Terraform Associate.
